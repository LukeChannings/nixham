# Welcome to Nixham <img src="./docs/hedgehog.png" alt="🦔" height="52px" width="52px" />

Nixham (_/ˈnixəm/_) is a small hamlet containing Nix stuff that hasn't yet been absorbed by Greater Nixester.

## Geography

- `modules/`
  - `nixos/` - NixOS modules. Available under `modules.nixos` and `nixosModules`
  - `nix-darwin/` - `nix-darwin` modules. Available under `modules.darwin` and `darwinModules`
- `docs/modules/` - [module options](./docs/modules/README.md), generated by `just docs`
- `packages/` - Nix packages. Available under `packages.${platform}`
- `profiles/` - compositions of modules and packages for my systems.
- `.forgejo/actions/` - composite actions for GitHub and Forgejo
  - `substituter/` - substitute from `nix.channings.me`
  - `niks3-push/` - push store paths to `nix.channings.me` through niks3
  - `oci-publish/` - push an image to a registry when its closure changes
  - `upstream-sync/` - bring a fork's upstream commits in through a PR

## Syncing a fork with its upstream

A forge repo forked from an upstream calls `upstream-sync` on a schedule:

```yaml
"on":
  schedule:
    - cron: "0 6 * * 1"
  workflow_dispatch:

jobs:
  sync:
    runs-on: nixos-latest
    steps:
      - uses: https://forge.channings.me/hartlandia/nixham/.forgejo/actions/upstream-sync@main
        with:
          upstream: https://github.com/kaiT2en/KaiT2en-Fedora
          token: ${{ secrets.FORGE_PAT }}
          signing_key: ${{ secrets.SIGNING_KEY }}
```
